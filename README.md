# Backend API System with Caching & Authentication

## Tech Stack
- Java
- Spring Boot
- Redis
- MySQL
- JWT Authentication

## Features
- REST APIs using controller-service architecture
- JWT-based authentication
- Redis caching
- MySQL database integration
- Fixed-window rate limiting
- Concurrent request handling using Spring Boot

## Run the Project
1. Configure MySQL and Redis
2. Run:
   mvn spring-boot:run

## API Endpoints
- GET /api/users
- POST /api/users
